## Objetivo

Apresentar experiência, especialidades, projetos e formação nas áreas de Engenharia de Dados, Analytics e Machine Learning em uma experiência direta, responsiva e acessível.

## Tecnologias

- HTML semântico
- CSS moderno
- JavaScript sem dependências
- GitHub Pages

O projeto não exige instalação, build ou framework.

## Executar localmente

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.
